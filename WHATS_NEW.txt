WAR_POWERS v2.8 - gene deletion / duplication screen (GRCh38)
============================================================
Screening only, NOT clinical. Confirm any hit in IGV and/or with a depth +
loss-of-heterozygosity (het-SNP) check before treating it as real.

What it does
  Scans every gene in genes_clean.txt in one 30x WGS BAM and compares the gene's
  average depth to (a) the immediately flanking DNA and (b) a genome-wide baseline,
  to flag possible copy-number loss or gain.

How a call is made  (v2.8 - SENSITIVITY FIRST)
  - Gene depth vs the per-chromosome genome baseline is the SOLE caller. A gene
    below DEL_HET_RATIO (default 0.75) of the baseline is flagged as a possible
    het/partial deletion; below FULL_DEL_ABS (5x absolute) as a likely full
    deletion; above DUP_RATIO (1.35) as a possible duplication.
  - The flanks (left_depth, right_depth, clean_flank, gene_to_clean_flank) are
    still measured and shown for CONTEXT, but they never gate or veto a call.
    Rationale: a missed deletion is invisible; a false positive is a 30-second
    loss-of-heterozygosity check. Flanks kept mis-firing in segmental-dup regions
    (inflated / contaminated), so they were demoted to context only.
  - Thresholds live at the top of WAR_POWERS.sh - raise DEL_HET_RATIO toward
    0.80/0.85 to surface even mild reductions (more candidates to confirm).
  - Confirm every hit with the depth + loss-of-heterozygosity check (a real het
    deletion shows ~0 balanced heterozygous SNPs across the gene).
  - Full deletion when gene depth is near zero (< 5x).
  - Duplication when the gene is well above both the flank and the baseline.

Handles the tricky cases
  - Deletions that extend into a flank (uses the clean flank + genome baseline).
  - X / Y scored against their own baselines (works for XX and XY; no karyotype
    input needed; no false Y-deletion calls in XX).
  - MT-* genes scored against whole-MT depth (heteroplasmy-aware review flag).
  - Auto-detects bare ("7") vs chr-prefixed ("chr7") BAMs.

Output (written next to the script)
  deletion_all_data.tsv   every gene + depths + call
  deletion_hits.tsv       only flagged deletions / MT review

Run
  Windows : double-click WAR_POWERS.bat   (needs WSL + samtools; the .bat sets up)
  Mac     : double-click WAR_POWERS.command (needs: brew install samtools)
  Any     : in a terminal in this folder:  bash WAR_POWERS.sh

v2.8 (based on v2.2 - baseline-only caller, flanks context-only, NO genome sampling,
      NO caching):
  - Deletion threshold tightened: DEL_HET_RATIO = 0.70 (was 0.75).
  - Gene panel expanded to 573 (added ACTL6A, ACTL6B, AGO1-4, NSD1-3).

v2.8: output columns simplified. Replaced the clean_flank / gene_to_clean_flank
  columns with a single gene_to_avg_depth ratio (gene depth / the sample's average
  depth) - which is exactly the value the call is based on. left_depth and
  right_depth are still shown for context. Columns are now:
  gene, chrom, start, end, gene_depth, left_depth, right_depth, avg_depth,
  gene_to_avg_depth, call.

v2.8: MUCH faster. Depth is now measured in ONE samtools bedcov pass over all
  gene + flank intervals, instead of ~3 samtools depth calls per gene (~1,700 for
  the full panel). Same numbers (mean depth per region), same calls - just one
  process and one index load instead of thousands. Note: absolute depths can differ
  by a hair vs older versions (bedcov sums coverage slightly differently than
  per-base depth), but the ratios and calls are unaffected.
  Tip: on WSL, the BAM sitting on the Windows C: drive (/mnt/c) is the other slow
  factor - reading a 33 GB BAM over /mnt/c is slower than a native Linux path.
